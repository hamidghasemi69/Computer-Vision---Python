## 📌 Overview

A complete, hands-on path through classical and deep-learning computer vision in Python: from images as NumPy arrays, to real-time video, feature detection, object tracking and convolutional neural networks. Each module ends with an assessment and its solution.

> 📚 **About this repository:** these are my study notebooks and exercise solutions from an online course. The course materials are © Pierian Data Inc. and are shared here for personal learning and reference.

## 🧭 What's inside

| # | Module | Topics |
|---|---|---|
| 00 | **NumPy & image basics** | NumPy arrays, images as arrays, pixel manipulation |
| 01 | **Image basics with OpenCV** | Opening and displaying images, drawing shapes and text, drawing with the mouse |
| 02 | **Image processing** | Color spaces, blending and pasting, thresholding, blurring and smoothing, morphological operators, gradients, histograms |
| 03 | **Video basics** | Connecting to a webcam, reading and writing video files, drawing on live video |
| 04 | **Object detection** | Template matching, corner and edge detection, grid and contour detection, feature matching, watershed segmentation, face detection |
| 05 | **Deep learning for computer vision** | Keras basics, CNNs on MNIST and CIFAR-10, training on custom images |

## 🚀 Getting started

```bash
git clone https://github.com/hamidghasemi69/Computer-Vision---Python.git
cd Computer-Vision---Python
conda env create -f Computer-Vision-with-Python/cvcourse_macos.yml   # or _linux / _windows
conda activate python-cvcourse
jupyter notebook
```
